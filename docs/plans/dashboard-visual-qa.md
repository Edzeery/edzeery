# قائمة تحقق المراجعة البصرية — داشبورد التاجر

الهدف: تمكين المراجع البشري من إرسال لقطات مرتّبة لمراجعة التابات الأربعة في الداشبورد
(تأكيد/Count، تأكيد/Rate، توصيل/Delivery، الأفضل/Top). هذا المستند هو قائمة الفحص فقط —
لا يعدّل أي كود إنتاجي.

## المتطلبات
- حساب بدور OWNER وله الصلاحيات الكاملة (التابات الثلاث لا تظهر إلا لمن يملك صلاحياتها).
- بيانات متجر كافية: طلبات بحالات مختلفة، عضو فريق واحد على الأقل، منتج واحد على الأقل
  مرتّبط بطلب، وشركة توصيل واحدة على الأقل.

## كيف تضبط الحالة
- **المقاسات:** 375px (جوال) / 768px (تابلت) / 1440px (سطح مكتب).
- **الاتجاه:** RTL (لغة `ar`) و LTR (لغة `en` مثلًا).
- **الثيم:** فاتح وداكن عبر مفتاح الثيم.
- **التابات:** من شريط التابات أعلى الصفحة (فوق شريط الفلاتر).

## نطاق الفلاتر لكل تاب
| التاب | الفترة | العضو | المنتجات | أساس التاريخ | شركة التوصيل |
|---|---|---|---|---|---|
| تأكيد | ✔ | ✔ (إن لم يكن العضو مقفلًا) | ✔ | ✔ (created/confirmed) | ✖ |
| توصيل | ✔ | ✔ (إن لم يكن العضو مقفلًا) | ✖ | ✖ | ✔ |
| الأفضل (Top) | ✔ | ✖ | ✖ | ✖ | ✖ |

## 1) اللقطات الأساسية (إلزامية) — الوضع الفاتح
لكل تاب من الأربعة: **375 / 768 / 1440** × **RTL / LTR**، بالحالة الافتراضية بلا فلاتر.

- [ ] تأكيد Count — 375/768/1440 — RTL + LTR (لقطتان لكل مقاس)
- [ ] تأكيد Rate  — 375/768/1440 — RTL + LTR
- [ ] توصيل        — 375/768/1440 — RTL + LTR
- [ ] الأفضل Top   — 375/768/1440 — RTL + LTR

## 2) الثيم الداكن
لكل تاب من الأربعة: **375 / 1440** × **RTL / LTR**.

- [ ] تأكيد Count — 375/1440 — RTL + LTR
- [ ] تأكيد Rate  — 375/1440 — RTL + LTR
- [ ] توصيل        — 375/1440 — RTL + LTR
- [ ] الأفضل Top   — 375/1440 — RTL + LTR

## 3) حالات الفلاتر (على 1440، الوضع الفاتح)
- [ ] تاب التأكيد — عضو محدّد.
- [ ] تاب التأكيد — منتج محدّد (يظهر شريط الفلاتر النشطة + زر التصفير).
- [ ] تاب التأكيد — أساس التاريخ = `confirmed` (تظهر شريحة "آخر تغيير حالة").
- [ ] تاب التأكيد — فترة مخصّصة (Custom) وحقلا التاريخ، مع حالة نطاق غير صالح.
- [ ] تاب التوصيل — شركة توصيل محدّدة.
- [ ] تاب التوصيل — عضو محدّد.
- [ ] أي تاب — حالة فارغة (بلا طلبات في النطاق) لاختبار الحالة الفارغة.

## 4) فحوصات تفاعلية/وصول (تحقق يدوي)
- [ ] شريط التابات **موسّط** أعلى الصفحة، **فوق** شريط الفلاتر.
- [ ] لكل تاب **أيقونة**: تأكيد = دائرة صح، توصيل = شاحنة، الأفضل = سهم صاعد.
- [ ] التاب النشط كحبة (pill) بارزة، وغير النشط باهت.
- [ ] **لوحة المفاتيح:** Tab يصل للتابات، ثم ←/→ للتنقل بينها (RTL-aware)، ثم Home / End.
- [ ] لا يوجد فيض أفقي عند 375px في أي تاب.
- [ ] حالة التحميل تظهر عند تغيير تاب/فلتر ثم تُحدّث اللوحة.
- [ ] المؤشرات متسقة: بطاقات AOV/نسبة الإرجاع في تاب الأفضل فقط، وبطاقتا المعدّل/في انتظار
  التأكيد في تاب التأكيد فقط، وقائمتا أفضل المؤكّدين/المسلّمين في تاب الأفضل فقط.

## 5) تسمية الملفات
`{view}-{tab}-{width}-{dir}-{theme}-{variant}.png`

مثال: `confirmation-count-375-rtl-light-default.png`،
`delivery-1440-ltr-dark-carrier.png`، `top-768-rtl-light-default.png`.

## 6) ما الذي يُرسل
- الأساسية (القسم 1) أولًا — الحد الأدنى.
- ثم حالات الفلاتر (القسم 3).
- والثيم الداكن (القسم 2) إن أمكن.
- مع أي لقطة فيها خلل، أرفق: المقاس + الاتجاه + الثيم + الفلاتر المفعّلة.
